1. Create virtual environment for pyhton in the {HOME} directoty of the user that will be calling the scripts.
  1.1 In the Home directory run: python3 -m venv venv_matogen
2. Install the required libraries for the virtual environment
  2.1 Activate the virtual environment: source "${HOME}/venv_matogen/bin/activate"
  2.2 pip install pandas
  2.3 pip install psycopg
  2.4 pip install psycopg2
  2.5 pip install sqlalchemy
3. Deactivate the virtual environment.
4. Clone the GIT repository into the {HOME} directory.
